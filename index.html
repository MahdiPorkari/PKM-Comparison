How to read the comparison

Local First indicates whether data is stored locally on your device first (local-first) or requires a cloud server.

Markdown Export means the app can create .md files from its data.

Live .md Sync means the app edits ordinary .md files directly on disk, allowing standard file synchronization.

P2P Sync distinguishes built-in peer-to-peer syncing engines from external tools like Syncthing or Git.

Render Raw HTML means HTML typed into notes is rendered visually as webpage content rather than plaintext source.

Code Blocks / Highlighting means code snippets support syntax-aware coloring and formatting.

Quick picks for your criteria

  • Native types + P2P: Anytype.
  • Block Outliner + Real .md files + Completion Recurrence: Logseq OG or Tine.
  • Polished iOS/Mac Design + Blocks + Collections: Craft Docs.
  • Cloud Databases + Blocks + Collaborative Workspace: Notion.
  • Real .md files + Mature Android App: Obsidian.
  • Native types + Completion-based tasks (Cloud): Capacities.
  • Open Source Markdown Outliner: Reflect Open.
